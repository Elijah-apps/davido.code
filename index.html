Sheet 02 — Modes

Three ways to work, one sidebar.

Switch modes with a click. Each one changes what Davido Code hands back — not just how it talks.

MODE / 01

Ask

Chat about your code with full selection context. Streamed responses, code blocks you can insert straight into the editor with one click.

MODE / 02

Plan

Describe a feature. Get a numbered implementation plan, then watch it render as a step-by-step flowchart you can hand to a teammate.

MODE / 03

Architect

Describe a system. Get proposed components and how they connect, laid out as a draggable, color-coded diagram — not a wall of text.

MODE / 04

Generate

Create audio, image, or vector assets from a prompt. Preview them inline, then save to .davido/assets/.

Sheet 03 — Commands

Nine commands live on your selection.

Right-click any selection, or reach them from the command palette. No mode-switching required.

DETAIL A

Fix

Reads editor diagnostics on your selection, proposes a minimal correction, and offers Apply or Show Diff before touching anything.

DETAIL B

Explain

Breaks down a selection in plain English in the chat panel, with your surrounding file as ground truth.

DETAIL C

Test

Generates unit tests in the idiomatic framework for the file's language and opens them beside your code.

DETAIL D

Doc

Adds JSDoc or docstrings in place, preserving your logic exactly — no surprise refactors.

DETAIL E

Generate Audio

Describe a sound, waveform, or short audio snippet. Davido Code returns a .wav preview you can play directly in the sidebar.

DETAIL F

Generate Image

Prompt for a diagram, icon, or illustration. Get an SVG or PNG asset rendered inline and saved to your workspace.

Sheet 03b — Code Intelligence

Code-aware. Context-rich.

Davido Code doesn't guess — it reads your workspace, understands symbols, and suggests edits that fit your style.

CODE / 01

Symbol-aware refactor

Rename, move, or extract with full symbol understanding. Updates references across files.

CODE / 02

Inline completion

As you type, Davido Code suggests multi-line completions. Tab to accept, Esc to dismiss.

CODE / 03

Workspace diagnostics

Scans your entire project for lint issues, type errors, and suggests batch fixes from the panel.

Sheet 04 — Diagram Preview

It doesn't just describe a plan. It draws one.

Plan and Architect modes open a live preview panel beside your editor — rendered with flowchart.js and d3.js, bundled locally. Nothing leaves your machine to draw a diagram.

Sheet 05 — Generate Assets

Audio, images, vectors — from prompt to preview.

Describe what you want to hear or see. Davido Code generates, previews, and saves assets to .davido/assets/. Supported: .wav, .svg, .png.

AUDIO

Prompt → Waveform

"Ambient drone with a low pulse" → generates a 4-second .wav file with a visual waveform preview in the panel.

IMAGE

Prompt → Vector / Raster

"System diagram showing API gateway with three microservices" → returns an SVG diagram you can edit or export as PNG.

ASSET LIBRARY

Workspace-ready

All generated assets are stored in .davido/assets/ with metadata, ready to commit or reuse.

Sheet 06 — Bill of Materials

Bring your own model.

Davido Code speaks the OpenAI chat-completions schema. Point it at any provider that does too. Keys live in VS Code's SecretStorage — never in settings.json.

Provider davido.provider Default model Notes
OpenRouter "openrouter" mistral-small-3.2-24b:free Free-tier models available
Mistral "mistral" mistral-large-latest Direct API, no proxy
Custom "custom" any Self-hosted, Ollama, LM Studio
Sheet 07 — Install

Four steps to your first plan.

01

Install from the VS Code Marketplace, or run the command below.

02

Open the Davido Code panel — Ctrl+Shift+D.

03

Set a key for OpenRouter, Mistral, or your own endpoint.

04

Pick a mode. Ask a question, plan a feature, architect a system, or generate an asset.
